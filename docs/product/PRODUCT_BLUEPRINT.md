# FundGene 产品蓝图

更新日期：2026-04-29
状态：产品总设计基线。与 `AGENTS.md` 和 `PROJECT_OVERVIEW.md` 保持一致；旧的用户旅程和信息架构散文档已经合并到本文档与项目总览。

## 1. 产品定位

FundGene 是一个面向基金投资新手的 AI 投资陪练与决策支持产品。

它的核心不是替用户下决策，也不是输出交易口令，而是把新手从“碎片信息 + 情绪驱动”带到“解释充分 + 风险可见 + 决策可复盘”。

产品人格应当是：

- 克制
- 纪律性强
- 解释优先
- 训练优先

## 2. 目标用户

主用户：

- 初学或早期基金投资者
- 金融词汇和框架薄弱
- 容易被涨跌和热点信息带节奏
- 需要结构化讲解、证据和下一步动作

典型问题：

- “我应该怎么开始学基金？”
- “我这个组合到底风险在哪里？”
- “为什么我一跌就想卖？”
- “遇到历史大跌我应该怎么练习更理性地做决定？”

## 3. 核心问题

FundGene 要解决的不是“信息缺失”本身，而是以下六类真实痛点：

1. 认知缺口：概念和风险框架混乱
2. 风险错觉：把短期波动误当成能力或灾难
3. 噪音过载：信息很多，但不知道与自己有什么关系
4. 组合不可读：看不懂结构、暴露、集中度与缺口
5. 偏差不可见：追涨杀跌、损失厌恶等重复出现却没有复盘
6. 缺少训练场：没有低风险的历史情境练习环境

## 4. 核心模块

一级产品模块：

- 仪表盘
- AI 教练工作区
- 学习中心
- 行为画像
- 组合分析
- 情境模拟
- 新闻与政策解读

模块定位：

- 仪表盘：把本周最重要的行动、提醒和变化串起来
- AI 教练：用户的自然语言入口，也是各模块的智能协调入口
- 学习中心：新手知识路径、课程、测验和进度
- 行为画像：偏差标签、证据、训练计划
- 组合分析：组合体检、风险解释、调整原则
- 情境模拟：历史压力场景中的训练与复盘
- 新闻解读：把噪音变成“对我是否相关、为何相关”

## 4.1 信息架构与导航

当前主线导航应围绕真实闭环组织，而不是围绕旧原型页面组织：

1. 仪表盘
2. AI 教练
3. 学习中心
4. 组合分析
5. 情境模拟
6. 新闻解读

行为画像在当前实现中主要作为 dashboard、coach 和 simulation 的上下文能力存在。未来如果证据、训练计划和历史变化足够丰富，再独立成一级工作区。

## 4.2 核心用户旅程

首次使用旅程：

1. 用户进入 `/start` 注册或登录。
2. 用户完成 onboarding 和风险问卷。
3. 仪表盘生成当前画像、下一步动作和推荐路径。
4. 用户进入 coach 或 learning 完成第一步。

学习旅程：

1. 用户在 coach 提问或从 learning 进入课程。
2. 系统返回结构化解释和相关学习动作。
3. 用户完成 section 后，进度写回 dashboard。

组合分析旅程：

1. 用户手动录入持仓快照。
2. 后端生成结构化组合报告。
3. dashboard 与 coach 可引用最近报告。

行为训练旅程：

1. 用户选择历史情境。
2. 用户在关键节点提交动作。
3. 系统生成复盘，并把证据回流行为上下文。

新闻解读旅程：

1. 用户选择已有新闻/政策项，或粘贴自己的标题和正文。
2. 系统生成新手可读的影响解释、风险提示和下一步学习建议。
3. 最近一次解读可进入 dashboard 和 coach context。

## 5. 非目标范围

明确不做：

- 交易执行
- 自动下单或自动调仓
- 收益承诺
- 高风险投机建议
- 泛聊天机器人
- 为了炫技而设计的多 agent 网络

## 6. 用户主路径

### 6.1 首次使用

1. 登录或注册
2. 完成基础资料与风险问卷
3. 进入仪表盘，看到本周三件事
4. 进入 AI 教练或学习中心，开始第一步

### 6.2 每周使用闭环

1. 仪表盘生成本周计划
2. 完成一个学习单元
3. 完成一次组合体检
4. 完成一次微型历史情境训练
5. 系统更新行为画像和成长轨迹
6. 回到仪表盘看变化和下一步

## 7. 产品层级结构

产品对象层：

- 用户状态对象：风险画像、知识画像、行为画像
- 学习对象：课程、路径、进度、测验
- 组合对象：快照、持仓、分析报告、建议记录
- 训练对象：场景、事件、会话、行动、复盘
- 助手对象：会话、消息、agent run、引用、推荐记录

页面层：

- 仪表盘只展示最关键的行动、风险和变化
- 教练工作区必须输出结构化解释而不是纯长文本
- 学习中心先做“新手必修短路径”，不做泛内容库
- 行为画像必须绑定证据和训练计划
- 组合分析先做“看懂结构”，再做“调整原则”
- 情境模拟先做少量高质量场景

## 8. 第一阶段必须打通的闭环

闭环定义：

- 用户完成一次风险问卷
- 用户完成一次学习单元
- 用户完成一次组合体检
- 用户完成一次微型历史情境训练
- 系统更新至少一个偏差维度的证据
- 仪表盘能展示完成情况与下一步动作

只有满足这六点，才算第一阶段真正打通。

## 9. 最小可发布主干

MVP 必须包含：

- 认证与基础用户档案
- 风险问卷
- 仪表盘
- AI 教练工作区
- 学习中心
- 组合分析
- 结构化记录与可追溯 run / citation

MVP 可继续做极简或后续增强：

- 完整情境模拟工作区的场景扩充
- 自动化新闻抓取的来源治理、刷新策略和引用评估
- 大规模课程库
- 高级评测和多角色协作能力
